# EcoLingo

PWA de educación y asistencia para reciclaje desarrollada con React, TypeScript, Vite, Leaflet, Supabase y TensorFlow.js.

## Inicio rápido

```bash
npm ci
cp .env.example .env
npm run dev
```

Variables públicas del frontend:

```env
VITE_SUPABASE_URL=https://TU-PROYECTO.supabase.co
VITE_SUPABASE_ANON_KEY=TU_CLAVE_ANON_PUBLICA
```

La `SUPABASE_SERVICE_ROLE_KEY` **no debe** usar prefijo `VITE_` ni llegar al navegador.

## Supabase

### 1. Sugerencias de la comunidad

```sql
create table if not exists public.community_suggestions (
  id bigint generated by default as identity primary key,
  name text not null,
  address text not null,
  latitude double precision,
  longitude double precision,
  materials text[] not null default '{}',
  status text not null default 'pending',
  created_at timestamptz not null default now()
);

alter table public.community_suggestions enable row level security;

create policy "Anyone can submit suggestions"
  on public.community_suggestions for insert
  with check (status = 'pending');
```

Si la policy ya existe, no la vuelvas a crear.

### 2. Puntos limpios oficiales

Ejecuta en el SQL Editor:

`supabase/migrations/20260906_recycling_points_realtime.sql`

La migración es compatible con una instalación nueva y con la tabla original. Añade trazabilidad de fuente, fecha de verificación, estado, índices y publicación Realtime.

## Sincronización de puntos del MMA

La sincronización usa la clave privada solamente en un entorno seguro:

```env
SUPABASE_URL=https://TU-PROYECTO.supabase.co
SUPABASE_SERVICE_ROLE_KEY=TU_SERVICE_ROLE
```

Ejecución manual:

```bash
npm run seed:mma
```

También se incluye `.github/workflows/sync-mma.yml`, que puede ejecutarse diariamente desde GitHub Actions. Configura allí los secretos `SUPABASE_URL` y `SUPABASE_SERVICE_ROLE_KEY`.

La sincronización consulta una malla geográfica solapada, deduplica por identificador de fuente y solo retira registros antiguos **después** de completar correctamente los upserts. Una caída del MMA no vacía la última copia válida.

## Puntos en tiempo real

El frontend pagina toda la tabla de `recycling_points` y se suscribe a eventos `INSERT`, `UPDATE` y `DELETE` mediante Supabase Realtime. “Tiempo real” se refiere a los cambios ya presentes en Supabase; la frescura de la fuente oficial depende de la última sincronización ejecutada.

Sin conexión, la aplicación intenta mostrar la última copia válida guardada localmente e informa que puede estar desactualizada.

## Escáner

MobileNet/ImageNet se conserva únicamente como **señal visual auxiliar**. No es un modelo especializado en residuos. La aplicación:

- traduce solo etiquetas visuales explícitamente conocidas;
- calcula una confianza conservadora;
- distingue `confident`, `uncertain` y `unknown`;
- nunca convierte una predicción desconocida en plástico u otra categoría por defecto;
- exige confirmación manual cuando la evidencia es insuficiente;
- permite subir una foto, cambiar de cámara y corregir la categoría;
- intenta leer códigos de barras con `BarcodeDetector` cuando el navegador lo soporta y consulta metadatos de envase en Open Food Facts;
- trata los metadatos de envases multimaterial como evidencia ambigua que requiere confirmación;
- libera los `MediaStreamTrack` al cerrar o terminar una captura.

La consulta por código de barras es un complemento y depende de que el producto tenga metadatos de envase disponibles.

## Clasificación con IA (NVIDIA Build)

El escáner combina tres fuentes de evidencia: el modelo multimodal remoto, el código de barras y MobileNet en el dispositivo. La IA remota es opcional: si no está configurada, el escáner sigue funcionando con las otras dos.

La clave `nvapi-...` **nunca llega al navegador**. El frontend siempre habla con un proxy que la añade del lado del servidor.

### 1. Obtener la clave

Crea una API key en [build.nvidia.com](https://build.nvidia.com) (formato `nvapi-...`).

### 2. Desarrollo local

Añade a tu `.env`:

```env
NVIDIA_API_KEY=nvapi-TU_CLAVE
```

`vite.config.ts` levanta un proxy en `/api/nvidia` que inyecta la cabecera `Authorization` en el proceso de Node. La variable no lleva prefijo `VITE_`, así que no entra en el bundle.

### 3. Producción

Despliega la Edge Function incluida:

```bash
supabase secrets set NVIDIA_API_KEY=nvapi-TU_CLAVE
supabase functions deploy ai-classify
```

El cliente usa por defecto `${VITE_SUPABASE_URL}/functions/v1/ai-classify`. Si prefieres otro proxy (Cloudflare Worker, Vercel, etc.), indícalo con `VITE_AI_PROXY_URL`.

### Modelo

Por defecto `meta/llama-3.2-90b-vision-instruct`. Se cambia con `VITE_NVIDIA_MODEL`; la Edge Function acepta solo una lista blanca de modelos de visión para que no pueda usarse como proxy abierto.

### Cómo se combina la evidencia

| Prioridad | Fuente | Resultado |
| --- | --- | --- |
| 1 | IA con confianza ≥ 0.6 | `confident` si ≥ 0.78 o si coincide con el código de barras; si discrepan, `uncertain` |
| 2 | Código de barras (Open Food Facts) | Como antes de la integración |
| 3 | MobileNet local con confianza ≥ 0.62 | Sugerencia visual |
| 4 | IA con confianza < 0.6 | Sugerencia a confirmar, nunca preseleccionada |
| 5 | Sin evidencia | `unknown`; el usuario elige la categoría |

La preselección automática sigue ocurriendo solo cuando el resultado es `confident`. Para una clasificación visual especializada sigue siendo recomendable entrenar y desplegar un modelo de residuos con un dataset representativo de las categorías de EcoLingo.

## Validación

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

`npm test` contiene casos mínimos para clasificación conocida y entradas ambiguas.

## PWA

`vite-plugin-pwa` es la única estrategia de PWA. El manifest y service worker se generan durante el build. Los iconos principales están en `public/` en tamaños 192, 512, maskable 512 y Apple Touch 180.
